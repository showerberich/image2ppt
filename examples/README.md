# 素材示例：网络图片 → 可编辑 PPTX

下面这些**不是设计源文件**，而是把网络上的设计稿图片交给
[image2ppt.asia](https://image2ppt.asia) 自动转换后的结果示例。

每一页给三件东西：

| 文件 | 是什么 |
|---|---|
| `原图.jpg` / `第NN页_原图.jpg` | 网络上的设计稿图片（转换输入） |
| `成品.pptx` / `第NN页_成品.pptx` | 转换输出：文字是原生文本框，色块、箭头、图标是原生形状，打开就能改 |
| `成品预览.jpg` / `第NN页_预览.jpg` | 成品的渲染图，不开 PowerPoint 也能看效果 |

> 这里只放**少量示例目录**，方便直接看转换效果，不提供整包或压缩包下载。
> 完整素材（222 页，按科研学术 / 项目汇报 / 年终总结 / 规划路线图等分类）
> 在 [image2ppt.asia 的素材页](https://image2ppt.asia/#mat) 逐页浏览、单页下载。

## 🧭 怎么看

1. 打开任意 `成品.pptx`，双击文字就能改；色块、箭头、图标都能单独选中。
2. 对照同目录的 `原图.jpg`，看哪些内容被重建成原生对象、哪些仍是图片。
3. 想用自己的图试一次：直接上传到 [image2ppt.asia](https://image2ppt.asia)，
   或用仓库里的 [API 客户端](../README.md)。
